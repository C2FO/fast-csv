title: Installation

> [!NOTE]
> `fast-csv` supports [Node.js LTS releases](https://nodejs.org/en/about/releases/) **22.x and 24.x** (`engines.node`: `^22.0.0 || ^24.0.0`). EOL and non-LTS lines are unsupported.
> See [endoflife.date/nodejs](https://endoflife.date/nodejs) for current LTS status.

## fast-csv

```sh
npm i -S fast-csv
```

## @fast-csv/parse

```sh
npm i -S @fast-csv/parse
```

## @fast-csv/format

```sh
npm i -S @fast-csv/format
```
